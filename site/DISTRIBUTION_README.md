# SIGNAL//5 Pages distribution

This public repository contains only the static GitHub Pages distribution of SIGNAL//5.
The local development source and the licensed mobile-device preview template are intentionally not redistributed here.

The website is publicly reachable but intentionally requests no search indexing.
Application code, educational content, and project artwork are not offered under an open-source license; all rights are reserved.
Third-party notices are included in `site/third-party-notices.txt` and `site/licenses/`.
